# My personal page

Just a simple portfolio / résumé.

## Dependencies

- [deno](https://deno.com/) : Render scriptings
- [sass](https://sass-lang.com/) : Style compiler
- [bulma](https://bulma.io/) : Style framework
- [pug](https://pugjs.org) : Template compiler

## Build

Run the build script

```console
deno task build
```
