## Dependencies

- [deno](https://deno.com/): Render scriptings
- [sass](https://sass-lang.com/): Style compiler
- [bulma](https://bulma.io/): Style framework
- [pug](https://pugjs.org): Template compiler
- [Material Design Icons]("https://pictogrammers.com/library/mdi/): SVG icons

## Build

Run the build script

```console
deno task build
```

## Serve

Serve static file in build directory to localhost:8000.

```console
deno task serve
```
